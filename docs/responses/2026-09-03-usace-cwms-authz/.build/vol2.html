Summary

Frasier Digital has no CPARS record; the questionnaire is provided in its place, as instr. 2.2.1.2.1 and the Government's Q&A answer 24 permit.

General scope of work as it relates to this PWS Design, ground-up development, and operation of a web platform serving thousands of users (bus drivers, teachers, administrators) across all Harris County school districts and every other entity dependent on Region 4's SCORM system. Frasier Digital built the entire system with no inherited codebase: the authentication backend and role-based access control governing what each class of user could see and do; REST services; integration with an incumbent third-party API (SCORM Cloud) for course delivery; course ingestion and validation; completion and qualification tracking; reporting and exports; and learning-platform administration. The parallel to this PWS is structural: an access-control layer that non-technical administrators depend on, an administrative interface over it, integration into an existing ecosystem, tests and validation protecting data integrity, and sustained maintenance after go-live.
