## 9. Risks / gotchas

1. **Unsigned Execution of Offer** or missing HSP = automatic out (R:2079, R:410). Fill every EoO block (name, title, address, phone, date).
2. **HSP filled the wrong way** (GFE sections instead of Section 2a self-performance) or left unsigned. Use the current Comptroller form version; verify the TTUHSC HUB page for a preferred form.
3. **Addenda Checklist** missing Addendum 1 initials; a late Addendum 2 could post up to 9/21 (A:4839) — re-check ESBD and TechBid before upload.
4. **Rate card dated Aug 31, 2027** (RFP text) instead of Mar 31, 2028 (Amendment 3). Same trap for term end. Grep the whole workspace for "2027" before build.
5. **Travel priced as a separate reimbursable** — must be inside each deliverable's fixed fee (A:1292).
6. **Production/hosting costs buried in the fixed fee** — must be optional line items, or we eat them (A:406-416).
7. **Insurance exposure**: RFP text says GL/auto $250k/$500k (R:1091-1104) but Q157 states CGL $2M agg / Auto $1M / EL $1M / Crime 50% of contract. Get quotes now; certificates due at award; propose modifications (drop auto if no owned vehicles) as a §7 exception. Cyber/E&O unspecified — carry it anyway.
8. **Uncapped indemnity + works-for-hire IP** (R:1067-1071, R:2110-2116): file a short tabular exception for pre-existing IP carve-out and mutual LoL; keep it minimal — deadlock is the only disqualification path (A:1470).
9. **No sandbox** (A:843): budget our own Azure/M365 dev tenant and any model API costs inside D4's fee.
10. **US-only data + no institutional data into any AI tool without written authorization** (A:328-333): state explicitly that all personnel and environments are US-based and that we run no TTUHSC data through third-party models absent approval.
11. **TX-RAMP**: propose in-tenant Power BI/SharePoint delivery so TX-RAMP stays N/A; if we offer a hosted option, label it optional and note provisional-cert path (A:2394-2401).
12. **Scoring**: 55% Service Specifications with no sub-weights — evaluators will score deliverable by deliverable; missing any of A–G or any of D1–D6 tanks the score. Address all six even if one is thin.
13. **Competition signal**: 658 questions, foreign primes allowed, large SIs present. Our edge is a compliant, tight, in-tenant, Texas-based, fixed-price bid — not breadth.
14. **Public information**: everything becomes public after award (R:221-229); mark trade secrets narrowly.
15. **Name-use**: TTUHSC name in future marketing needs written approval (A:4682).
16. Texas registrations (SOS, Comptroller account status, CMBL) are pre-award but the Franchise Tax certificate is a 5.2 item — pull it from the Comptroller site now.

1. **A form error kills a good proposal.** Unsigned Execution of Offer, an HSP without the Section 2a self-performance justification, or an un-initialed Addenda Checklist ends the bid before scoring. Build the forms first, verify them visually, and re-check the portals for Addendum 2 on 9/21.
