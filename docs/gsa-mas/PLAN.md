# GSA MAS Action Plan — Frasier Digital, LLC

Companion to [READINESS.md](READINESS.md). Written 2026-08-21. All durations are planning estimates; GSA-side figures are industry-reported ranges, not commitments.

## The strategy in one paragraph

Frasier cannot clear the two-year corporate-experience and financial-statement gates on a standard offer until ~January 2028, and the only earlier route (Startup Springboard) is gated on FASt Lane agency sponsorship. So the plan runs three workstreams in parallel: **(1) resolve the entity/predecessor question and ask GSA whether pre-LLC operations count** (cheap, could unlock a standard offer a year early), **(2) hunt a FASt Lane sponsor from the existing pipeline** (the only fast path), and **(3) build the offer package now** — nearly all of it is path-independent, perishable references need locking immediately, and a finished package lets Frasier submit within ~2 weeks of whichever gate opens first. Default landing if neither gate opens early: submit **Feb–Mar 2028**, award **mid–late 2028**.

### Phase 3 — Gate-dependent submission

**Path A — Springboard/FASt Lane (if a sponsor letter lands):**
1. Sponsor's written request to GSA ITC naming Frasier and the requirement (sponsor's contracting office writes it; Claude can draft talking points for Joseph's ask). Duration: entirely sponsor-dependent — realistically 2–8 wks from a warm "yes."
2. Confirm FASt Lane intake with ITC; finalize Springboard variants (financial substitutes, key-personnel substitutions per D3).
3. Submit in eOffer; staff for 24-hour turnarounds on CO questions during review.
4. Evaluation ~45 days (FASt Lane) → negotiation (rate haircuts likely; know the walk-away floor) → Final Proposal Revision → award.
**Elapsed from sponsor-yes to award: ~2.5–4 months.**

**Path C — Standard offer via predecessor ruling (if GSA says yes to D2/0.4):**
Submit ~4–6 weeks after the ruling (financials are the long pole) → evaluation 4–9 months → **award ~mid-2027**. Watch: Region 4 must stay inside the Factor Four 2-year window (until Oct 2027) — submit no later than early 2027 for comfort.

**Path B — Default (age in):**
- Through 2027: keep winning; any federal prime work generates CPARS and company-performed references (SSS RS, CDC VAERS, NOAA are all candidate Factor Four projects that would replace an aged-out Region 4).
- Oct–Dec 2027: refresh package against the then-current refresh; redo Pathways/readiness if >12 months old; close FY2027 books fast.
- **Jan–Feb 2028:** FY2027 + FY2026 statements ready; two-year corporate experience clears (entity start Jan 6, 2026).
- **Feb–Mar 2028: submit.** Evaluation 4–9 months → **award ~Q3–Q4 2028.**

### Phase 4 — Post-award obligations (whenever award lands)
- Accept TDR mod; report transactional data (zero-sales reports still required) and remit 0.75% IFF; expect tightened enforcement.
- Upload catalog/price list (GSA Advantage/FCP per current process); register for eBuy and start monitoring 54151S RFQs — the entire point.
- Track I-FSS-639: $100k reported sales by month 60, $125k per 5-year period after.
- Keep SAM active (renew before May 27, 2027 — this falls due mid-evaluation on Paths A/C).
