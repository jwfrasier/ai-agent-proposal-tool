# CMBL registration — paste sheet (Joseph does this one; it needs an eSystems login)

**Where:** https://comptroller.texas.gov/purchasing/vendor/cmbl/ → "CMBL Application" →
https://security.app.cpa.state.tx.us/ → **Create profile** (your user ID + password; Claude
cannot create accounts) → Vendor Registration → CMBL. Fee **$70/yr**, card or e-check at the end.
Takes ~15 minutes. Certificate/confirmation arrives by email; vendor ID appears in CMBL search.

**Why bother:** state agencies pull bid lists from the CMBL by NIGP class code; ESBD posts
solicitations. It is not a certification (Texas HUB is gone — VetHUB is SDV-only), it is a
mailing list with teeth. $70 is the entire cost of being visible to every Texas agency buyer.

## NIGP commodity codes to select (use the in-form NIGP search; pick the item codes under these classes)

- **920 — Data Processing, Computer, Programming, and Software Services**: software development / programming services; application development; system analysis and design; data processing; web site design and hosting; **artificial intelligence / machine learning services** if listed; cloud services.
- **918 — Consulting Services**: computer / information technology consulting; management consulting (data governance, AI strategy).
- **209 / 208 — Software**: only if you intend to sell licensed software (skip for now).
- **924 — Educational / Training Services**: computer training, curriculum development (Region 4 / LDOE lane).

Pick 8–15 item codes; more codes = more bid notices, no downside except email volume.

## After you submit

1. Save the confirmation PDF to `docs/texas/`.

3. Set an ESBD saved search (https://www.txsmartbuy.gov/esbd) for NIGP 920/918 — that is where the solicitations actually post.
